# Rose Sisterhood Onboarding

A simple React app to organize Rose Sisterhood meeting events.

## Features

- Create events with title, date, time, and description (admin page)
- Share unique event links for signup
- Event page displays info and allows guests to sign up with their name and note
- Participant list visible on the event page

## Usage

1. `npm install`
2. `npm start`
3. Visit `/admin` to create a new event and share the event link.

---

> For demo purposes, event and participant info uses local JSON files. For production, connect to a backend/database.
